# Feed & Discovery / application / read-models

Modelos de leitura montados a partir de eventos, otimizados para a tela.

## Arquivos previstos

| Arquivo | Responsabilidade |
|---|---|
| GeneralFeed.js | Itens recentes de todos os criadores, paginados por page e limit. |
| FollowingFeed.js | Itens apenas de quem a pessoa segue. |
| SearchIndex.js | Índice de busca por título, categoria e criador. |
