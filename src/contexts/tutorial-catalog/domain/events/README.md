# Tutorial Catalog / domain / events

Eventos de domínio: fatos que aconteceram, nomeados no passado, que interessam ao negócio.

## Arquivos previstos

| Arquivo | Responsabilidade |
|---|---|
| TutorialPublished.js | Tutorial publicado. |
| TutorialDetailsChanged.js | Título ou descrição alterados. |
| TutorialCoverReplaced.js | Capa trocada. |
| TutorialDeleted.js | Tutorial excluído; os outros contextos limpam seus dados. |
| TutorialHidden.js | Ocultado por moderação. |
| TutorialRestored.js | Voltou a ser publicado. |
| CategoryCreated.js | Nova categoria. |
